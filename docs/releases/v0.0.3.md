# Widget Core v0.0.3 — a more reliable desktop preview

Widget Core 0.0.3 brings the current widget manager and process-lifetime fixes into one experimental preview.

- Search your installed widgets, install a local package folder, and add, duplicate, configure or remove instances from the manager.
- Hide and show desktop widgets without losing their individual settings or placement.
- Stop old widget processes surviving a Core restart or uninstall. Each runner now belongs to the supervisor that started it.
- Retry transient shell activation failures during installation, with rollback when activation still fails.

The shared declarative renderer remains available alongside isolated QML packages. World Clock’s four QML designs remain the default experience.

Rust, QML, sandbox, Wayland and resource-isolation CI passed on the release PR. Portable acceptance covered settings persistence, independent instances, update/rollback and manager interaction at 100%, 125%, 150% and 200% scaling.

**This is an experimental preview.** XPS focus, lock-screen, monitor, suspend/reboot and multi-widget CPU/memory acceptance remain open. API 3 is unchanged; optional reveal remains disabled by default. Earlier 0.1.x development numbers did not indicate stability.

Update an existing Core checkout to this tag, then run:

```bash
git fetch origin --tags
git switch --detach v0.0.3
bash install-local --update
```

For a first installation, use `bash install-local`. If upgrading from the old in-process host, run `omarchy restart shell` once. Open the manager with `omarchy-widget manage`.

Pair this with [World Clock v0.0.3](https://github.com/tcballard/omarchy-widget-worldclock/releases/tag/v0.0.3). When reporting a problem, include your Omarchy version, display scale and whether it survives `omarchy-widget restart`.
