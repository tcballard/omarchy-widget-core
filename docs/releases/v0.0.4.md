Core can now feed your GitHub contribution graph to a desktop widget. v0.0.4 is a testing preview.

- Adds permission-controlled public GitHub calendar data, with caching and bounded requests. No token needed.
- Supports [GitHub Widget v0.0.1](https://github.com/tcballard/omarchy-widget-github/releases/tag/v0.0.1) through the shared SDK. Install the widget separately.

Update an existing Core checkout:

```bash
git fetch origin --tags
git switch --detach v0.0.4
bash install-local --update
```

Use `bash install-local` for a first installation. Upgrading from the old in-process host also needs one `omarchy restart shell`.

Automated CI passes. Live XPS network, focus, lock-screen, monitor and suspend/reboot testing remains open. API 3 continues; v0.1.0 is the supported-release target across Core and the widgets.
